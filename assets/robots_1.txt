#
#   OPTION B (leak-free, recommended if the URL must stay secret): do NOT list the
#   page here at all. Delete the Disallow lines below so this file allows everything,
#   and rely on the page's own noindex meta tag plus an X-Robots-Tag: noindex header
#   served on just that one path. Crawlers that fetch the page are told not to index
#   it, and the secret path never appears in robots.txt. See ghost-mode-server-config.md
#   for how to scope the X-Robots-Tag header to a single path.
