Publish as

Sets where NEW drafts will publish, stamped into each post at the moment it is created. Personal profile: the post appears under the connected person's own LinkedIn profile, outside the organization analytics and advocacy loop; use it for founder-voice commentary. Organization Page: the post appears on the company page, feeds the Analytics metrics, and becomes eligible for member amplification; use it for brand content (requires a connected org page). Changing this never retargets posts already in the queue; every post keeps the Org or Per badge it was created with. Per-post overrides still win over this setting.

Set Tokens Manually

For externally obtained token pairs. Both tokens are required and stored atomically; a partial pair stores nothing. Expiry seconds are optional: supplied, the refresher honors them; omitted, the next refresher sweep rotates the pair and establishes real expiries. Note that refresh never changes scopes; to change scopes use Reconnect above.
