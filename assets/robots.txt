# IMPORTANT tradeoff, read before using:
# robots.txt requests crawlers NOT to fetch the page. The X-Robots-Tag HTTP header
# and the in-page robots meta tag request crawlers NOT to index it. If you Disallow
# a URL here, a compliant crawler will not fetch it and therefore will never see the
# noindex directive. That is fine and desirable when the URL is never linked publicly,
# which is your case. The only scenario where Disallow can backfire is if someone links
# to the URL from another public site: a crawler could then list the bare URL with no
# content because it was told not to fetch it. If you ever expect inbound links and want
# a guaranteed no-index instead, remove the Disallow lines below and rely on the
# X-Robots-Tag header plus the page meta tags, which require the page to be fetchable.
